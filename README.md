# CV-Local

A Resume Customization tool that runs locally with Ollama models. This application allows you to:

1. Paste your resume
2. Paste a job description
3. Get a customized resume tailored to the job description

## Features

- Runs 100% locally - your data never leaves your computer
- Uses Ollama to run LLMs locally
- Supports multiple models (TinyLlama, Phi-2, Gemma, etc.)
- Simple web interface built with React + Vite

## Setup Instructions

1. Install [Ollama](https://ollama.ai/) on your computer
2. Pull your desired model(s) with `ollama pull tinyllama` (or another model)
3. Clone this repository
4. Run `npm install`
5. Run `npm run dev`
6. Open the application in your browser
